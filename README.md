# Archbee

Archbee is a documentation platform for product and API docs. This app brings it into your Make scenarios.

## What you can do

- Create, update, search, and delete documents.
- Manage spaces and space groups.
- Publish a space to preview or production.
- Import markdown and upload files.
- Sync OpenAPI specifications as API reference docs.
- Merge or discard suggested changes.
- Export organization content and read display rules.
- Start a scenario as soon as an event happens in your docs.

## Connect your account

You need two values from Archbee:

1. **Doc Space ID.** Find it in the space URL or in the space settings.
2. **API key.** Generate it under Organization Settings > API Access.

Enter both when you create the connection in Make.
